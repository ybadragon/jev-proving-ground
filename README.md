# jev-proving-ground

Synthetic cases for measuring whether the `verify-criteria` check actually catches
things. Every case starts as an issue written **before** any code exists, stating
behaviour rather than implementation.

Some implementations carry a planted defect. Which ones, and what the defect is, is
deliberately **not in this repo** — a session writing criteria here must not be able
to read the answer, or it has been handed the test.

Nothing here is real software. Do not depend on it.
